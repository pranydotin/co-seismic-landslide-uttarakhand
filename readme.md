# Landslide Susceptibility Mapping in Uttarakhand Using Frequency Ratio and Machine Learning

## Overview

This repository contains the computational workflow, scripts, notebooks, and documentation used for landslide susceptibility mapping in Uttarakhand using Frequency Ratio (FR) and Machine Learning approaches.

The workflow integrates geospatial analysis, Frequency Ratio-based susceptibility assessment, pseudo-absence generation, feature selection using Variance Inflation Factor (VIF), machine learning modeling, and susceptibility map validation.

## Methodology

The workflow consists of the following major stages:

1. Frequency Ratio (FR) computation
2. Weighted raster generation
3. Landslide Susceptibility Index (LSI) generation
4. LSI validation using AUC analysis
5. Pseudo-absence sample generation
6. Dataset preparation and preprocessing
7. Feature selection using VIF
8. Machine learning modeling
9. Susceptibility map generation and evaluation

## Repository Structure

* `docs/` – Documentation and supplementary materials
* `notebooks/` – Jupyter notebooks for analysis and model development
* `scripts/` – Python scripts used throughout the workflow
